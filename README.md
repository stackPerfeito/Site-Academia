# Projeto de Faculdade - Site de Academia 🏋️‍♂️

Este é um projeto acadêmico que desenvolve o **front-end** de um site para uma academia. O site apresenta informações como valores, promoções e outros detalhes relevantes para os clientes.

## Tecnologias utilizadas:
- **HTML** e **CSS** para a estrutura e estilização da página.
- **JavaScript** para interatividade.

🚀 O objetivo deste projeto é praticar desenvolvimento web, organização de código e versionamento no GitHub.

📌 **Observação:** Este repositório contém apenas o front-end, sem back-end ou banco de dados integrado.
